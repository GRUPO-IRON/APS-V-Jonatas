# APS V - Controle de Versão com Git e GitHub

## Objetivo
Aprender os conceitos básicos de controle
de versão utilizando Git e GitHub.

## O que foi aprendido
- O que é Git e GitHub.
- O que é controle de versão.
- Criação de repositórios.
- Commits e histórico de alterações.
- Diferença entre repositório local e remoto.

## Atividade
Repositório criado como parte da APS V,
com o objetivo de praticar os conhecimentos
adquiridos no curso de Git e GitHub.
